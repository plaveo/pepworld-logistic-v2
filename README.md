# PEPWORLD Logistics Intelligence V2

This package consolidates the approved V2 scaffold and responsive interface.

## Locked architecture

- ENG001–ENG120 — existing engine identifiers; titles pending official registry
- UI01–UI50 — reusable ecosystem-context display modules
- MC01–MC12 — geographic and evidence explanation cards
- Map cards do not issue GO / CAUTION / AVOID
- Demonstration output is NOT_COMPUTED
- No Zebra, CIS or production connection is included

## Validation

```bash
npm install
npm run validate:architecture
npm run lint
npm run build
```
